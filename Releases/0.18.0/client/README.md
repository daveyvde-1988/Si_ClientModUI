# Client 0.18.0 with original Si_ModUI_Server 1.4.4

The existing HELP / COMMANDS / MODS / SETTINGS shell, alphabetical left navigation, PLAYER / ADMIN buttons, appearance, input isolation, F6/F7, sidebar, feedback divider, overlays and saved settings are preserved. Only header/help version and companion-name text changes outside server-panel content.

Server panels now follow the friend's layout: ordered actions, inline switch choices, value input/SET rows, descriptions, information and tables. Catalogs use grouped flowing buttons, friendly labels and exact command tokens, with all-faction selection for admin Spawn. Disabled catalogs do not execute actions. Spawn has no currency display. Buy can refresh its balance explicitly through the advertised status action. Catalog/COMMANDS navigation, chat-menu choices, read-only balance browsing and player/team matrix pickers stay inside the existing panel. Player-specific table data comes from the companion's authenticated frame.

Networking now uses **SiModUI/2** only. The expanded document limit is bounded at four MiB; known table/catalog shapes validate before a complete frame commits. The cache namespace includes the marker and new panel format. Existing settings and saved commands retain their paths. Source provider APIs and the installed cheats provider are unchanged.

Per the user's choice, **the original friend's Si_ModUI_Server 1.4.4 is the active companion**. Our Si_ServerModUI.dll is retired with a verified backup. His original client Si_ModUI.dll is not installed because Si_ClientModUI supplies the retained shell. All 14 server DLLs from default-branch_0.9.47_2026-10-23 except Si_Logistics.dll are included unchanged. Keep our Logistics 0.9.3 and Formation DLLs. The `/elo balance` export conflict remains deferred to the friend. No gameplay DLL was patched or rebuilt.

The original companion owns server-side exports, filtering, refresh caching and console splitting. No patched alternative server is substituted. In particular, its personalized export support is values/tables; our separate server's extra personalized Formation-command extension is not part of this companion. Formation's registered/exported commands and chat menu remain the available fallback.

Build validation: client Release build has zero warnings/errors; 292 offline network/catalog/menu/persistence/panel checks pass. Checks cover the new marker, personal table shape, multi-select state, admin catalog audience, friendly label/token separation, disabled/currency flags, cache serialization and atomic malformed-frame rejection. The existing offline persistence harness was brought up to date with the already-established 0.17.3 deletion-marker behavior; sidebar buttons remain independently removable.

Install using `Install-DefaultBranch.ps1`, first with `-PlanOnly` if reviewing. It verifies release/game-reference hashes, refuses running affected games, backs up prior DLLs, installs the selected sides, retires overlapping UI DLLs and writes a schema-4 receipt. It does not edit configuration files or run cfg migration scripts. `Rollback-DefaultBranch.ps1 -InstallRecord <receipt>` restores previous DLLs and preserves settings. Copying the old companion back manually without retiring the active one would load both; use the rollback receipt.

No game/server is launched by packaging, installation or offline checks. Live testing should check the unchanged shell at normal text scale, a non-admin and admin session, Elo multi-select, Leaderboard tables, AntiCheat report refresh, Spawn faction/placement controls, Buy purchase/disabled state, and switching chat menus. The original companion and gameplay mods may create/migrate their own configuration folders on the next normal server start.
