# 0.3.0 release

Client and companion 0.3.0 add Formations, KoH Buy, Ranks and Help tabs; a collapsed faction header with two-stage F6 opening; two-second hover descriptions excluding formation choices; Locked Formation wording; warmer/translucent faction styling, 18 px text and full-menu FPS squad count. No action hotkeys were added.

KoH unit purchases use current server prices, explicit client confirmation and the original server purchase handler with original restrictions. The private adapter is pinned to the reviewed KoH DLL hash. Help reads active command registries plus known intercepted/contextual commands; missing argument descriptions are labelled. Ranks reads loaded configuration. Formation 2.15.0, Ranks 1.4.3, KoH/Logistics DLLs and server configuration are unchanged.

Client and companion Release builds passed with zero warnings/errors. No tests or game/server launches were performed; new behavior requires user live verification. See ../../TESTING.md, ../../NETWORKING.md and ../../INSTALLATION_STATUS.md for checks, protocol details and the verified backup record.
