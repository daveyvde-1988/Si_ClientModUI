Silica Mod Controller 0.9.0 - standalone client
Install MelonLoader for the Windows Silica client first.
With Silica closed, copy Mods/Si_SquadHUD.dll into your Silica/Mods folder.
No server companion is required. Do not install the old server DLL on the client.
F6 expands status; F6 again opens the menu. Help and mod tabs run commands only when clicked.
EDIT opens argument entry; SEND sends exactly one chat command. Opening tabs sends nothing.
Command availability/permissions depend on the server. Received menu choices expire.
SP MODS lists locally loaded mods in singleplayer; only exposed preferences/controls are editable.
Existing UserData/Si_SquadHUD layout files are retained. Live verification is pending.
