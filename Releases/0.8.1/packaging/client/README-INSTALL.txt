Si_SquadHUD client 0.8.1

For a Windows Silica client with the same working MelonLoader setup as this project. Close Silica before copying the DLL. Back up an existing Mods/Si_SquadHUD.dll, then extract this ZIP into the Silica game folder so the file is Mods/Si_SquadHUD.dll. Keep existing MelonLoader and UserData/settings. Join the server running SquadHUD companion 0.8.1 for the new features. Do not install server DLLs in the client.

In a loaded dedicated-server match: F6 expands status, then opens the full menu; F7 logs a status snapshot. Formation controls follow your role. Admin controls appear only with server Generic power. Unitbalance remains read only for players; admins use the separate Configure menus. Status chooses expanded HUD parameters, sidebar toggles the persistent commander strip, and notification bar routes mod notices into its own window. Ordinary player chat stays in chat.

Drag titles/grips and resize from bottom-right // grips. Open F6 for a cursor while arranging overlays; move the main menu aside if it covers one. Local per-user geometry, choices and enabled overlays save in UserData/Si_SquadHUD/layout-<SteamID64>.json. Existing old placement files migrate. No server settings or configuration are included. Notification history is memory-only (200 entries); X restores normal mod chat delivery. Unknown/custom or failed/oversized notification routes remain in chat.

This build compiled and its installation was hash-verified. Live verification is pending. After game updates, check compatibility with the server owner. No game/MelonLoader binaries, account data, server configuration or private URLs are included.

To remove it, close Silica and restore your previous DLL (or remove this DLL); keep UserData if you want the saved layout. Diagnostics is optional and is not included in this package.
0.8.1: steady disabled/tab styling; Mod status and Mod notifications labels; separate FPS/commander geometry; status choices default empty with expandable module groups; native server/Ranks chat fallback routes to notifications when enabled. Player chat stays in chat. Existing explicit choices and geometry migrate locally.
